Belajar GitHub: Antara Commit, Push, dan Kendala di Laboratorium

Dokumentasi pengalaman praktik menggunakan GitHub dan Visual Studio Code bersama tim IT kelas X TKJ. Tidak semua proses berjalan sesuai rencana, tetapi setiap kendala menjadi bagian dari pembelajaran.

Tanggal: Sabtu, 21 November 2026 Kelas: X TKJ Topik: Git & GitHub
01 / Pengalaman Praktik

Ketika Praktik Tidak Berjalan Sesuai Rencana

Pada pembelajaran hari ini, saya bersama tim IT dan siswa kelas X TKJ ALL mencoba mempraktikkan penggunaan GitHub melalui Visual Studio Code. Target pembelajaran adalah memahami alur kerja dasar Git, mulai dari menyiapkan repository hingga mengirim perubahan kode menggunakan perintah commit dan push. Namun, praktik belum berhasil diselesaikan karena terdapat beberapa kendala teknis yang ditemukan selama kegiatan berlangsung.

01

Aplikasi yang Terpasang Hilang Setelah Komputer Direstart

Kendala pertama ditemukan pada komputer laboratorium TKJ. Setiap kali siswa menginstal aplikasi desktop, seperti Adobe Premiere Pro maupun aplikasi lainnya, proses instalasi berhasil dan aplikasi dapat digunakan secara normal. Namun, setelah komputer direstart, aplikasi yang sebelumnya telah dipasang tidak lagi tersedia. Kondisi ini menghambat persiapan lingkungan kerja yang dibutuhkan untuk praktik Git dan GitHub.

02

Hambatan Saat Pendaftaran Akun GitHub

Kendala berikutnya terjadi ketika siswa mencoba membuat akun GitHub. Beberapa proses pendaftaran mengalami kegagalan setelah dilakukan percobaan berulang kali dari jaringan atau alamat IP yang sama. Dalam praktiknya, tombol pendaftaran sempat diklik berkali-kali dalam rentang waktu yang sangat singkat, sekitar tiga detik. Ada kemungkinan aktivitas berulang tersebut memicu pembatasan atau pemeriksaan keamanan dari GitHub. Akibatnya, proses pembuatan akun tidak dapat dilanjutkan dengan lancar.

02 / Refleksi Pembelajaran

Kendala Teknis Juga Bagian dari Proses Belajar

Dari praktik hari ini, saya menyadari bahwa keberhasilan menggunakan GitHub tidak hanya bergantung pada pemahaman perintah Git. Kondisi komputer, kesiapan perangkat lunak, koneksi internet, dan proses autentikasi akun juga berpengaruh terhadap kelancaran pembelajaran. Praktik akan dilanjutkan dengan memperbaiki kendala yang ditemukan agar siswa dapat memahami proses commit dan push hingga berhasil mengirim kode ke repository GitHub.
